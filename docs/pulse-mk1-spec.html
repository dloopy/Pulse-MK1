Core features
Tempo
BPM range 30–240, drag knob or scroll wheel
Tap tempo — T key or dedicated button
Start / stop — footswitch button or space
Debounced beat engine restart on drag (no audio glitching)
Time signature
Single cycle button — stacked fraction as icon, no text label
8 signatures in order of frequency (see table below)
Beat LEDs rebuild to match beats per bar on each change
Time sig badge in display top-right, moss green, matches button
Subdivision
Detented knob — 1/32 · 1/16T · 1/16 · 1/8T · 1/8 · 1/4T · 1/4 · 1/2 · whole
Physical pop animation + position locked on each step
Count-in
Independent toggle button, amber when active
One bar of amber LEDs + higher-pitched tick before metronome starts
CI badge in display bottom-right when active
Volume
Continuous knob, 0–100%
Scales click volume only, no UI feedback sounds
Tempo trainer
Play / Train mode switch — distinct colour language (terracotta vs steel blue)
In Train mode, knobs remap: Target BPM / Step size / Bars interval
Knob arcs shift to blue, labels update, display shows trainer config
Footswitch starts/stops the trainer advancement
Auto-increments BPM by step every N bars toward target
Progress bar fills along bottom of display as trainer runs
Stops automatically at target, progress bar fades
Step knob fully detented (1–20 BPM), bars detented (1–16)
Display animations (TE-inspired)
ASCII/monospace character animations alongside or replacing the BPM number depending on context. Functional art — each animation reflects something true about the musical state. DM Mono only, no SVG illustrations inside the display.
State Animation concept Behaviour
Stopped / idle Resting character — slow breathing pulse Plays on loop while metronome is stopped. Takes over full display.
4/4 playing Walking bassline tab scrolling left Small, sits left of BPM number. Syncs to beat.
3/4 playing Three-position pendulum swing Character swings left · centre · right with each beat.
6/8 playing Two groups of three dots breathing · · · pause · · · — pulses in compound groups.
5/4 / 7/8 playing Asymmetric block pattern Highlights odd groupings visually — e.g. ■■■□□ for 5/4.
Train mode running Climbing character or rising line Character position rises proportionally as BPM climbs to target.
Count-in Countdown bars — 4 · 3 · 2 · 1 Replaces BPM during count-in bar.
Target reached Brief celebration — e.g. \o/ Shows for ~1 second then returns to normal.

Interactions & keyboard
space — start / stop
T — tap tempo (3-second window, averages last taps)
Tempo knob — drag vertical, scroll wheel, sensitivity 0.9×
Sub knob — detented drag, 18px threshold per step
Vol knob — drag vertical, sensitivity 0.6×
Beat engine uses Web Audio API AudioContext scheduling — no setTimeout drift
Debounce restart on drag: 260ms after last knob movement
Dark mode — same pedal concept, inverted surface palette
Neo-brutalist theme toggle (same layout, different skin)
Pro version (mk2 — future)
Gap click / mute training — N bars on, N bars silent
Setlist / song presets with saved BPM + time sig
Swing / feel slider (0% straight → 50% swung)
Accent editor — per-beat accent pattern
Practice session timer
Polyrhythm mode
Click sound selector (woodblock, rim, hi-hat, sine, human voice)
Click on 2 & 4 only (backbeat mode)
Technical requirements
Web Audio API AudioContext for all timing — no setInterval for beats
Lookahead scheduler pattern (schedule beats ~100ms ahead)
React + Tailwind (Claude Code build)
No external audio libraries — synthesise clicks via OscillatorNode
All UI sounds: zero. Only metronome beat makes audio.
Mobile-responsive — touch drag on all knobs
LocalStorage for BPM, time sig, vol, mode persistence across sessions
